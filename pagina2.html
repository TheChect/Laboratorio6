02 / Redes

Conectar también es compartir

Un recorrido por los elementos que permiten comunicar nuestros equipos.

Router

El router conecta redes y dirige los paquetes hacia su destino. En una casa suele conectar la red local con la del proveedor de Internet. Aunque algunos equipos también ofrecen Wi-Fi, el enrutamiento y la conexión inalámbrica son funciones diferentes.

Switch

Un switch conecta dispositivos dentro de una red local. Utiliza direcciones MAC para decidir por qué puerto enviar las tramas cuando conoce su destino. Resulta útil para conectar varias computadoras mediante cables de red.

Cliente y servidor

Un cliente solicita un recurso y un servidor atiende esa solicitud. Al visitar una página, el navegador actúa como cliente y solicita los archivos necesarios. Este intercambio permite acceder a servicios desde diferentes dispositivos.

Una duda común

No. Wi-Fi conecta dispositivos de forma inalámbrica a una red local; esa red puede tener o no acceso a Internet.
