01 / Hardware

Las piezas detrás de cada idea

Conoce los componentes que hacen posible usar una computadora.

Procesador

El procesador ejecuta las instrucciones de los programas. Cuando abrimos una aplicación, realiza operaciones y coordina el trabajo con otros componentes. Su rendimiento depende de varios factores, como su arquitectura y la tarea que está realizando.

Memoria RAM

La memoria RAM guarda temporalmente los datos que los programas necesitan mientras están abiertos. Tener suficiente memoria permite trabajar con varias aplicaciones con menos interrupciones. Al apagar el equipo, esta información temporal se pierde.

Almacenamiento

El almacenamiento conserva archivos y programas después de apagar la computadora. Una unidad SSD permite acceder a los datos sin utilizar piezas mecánicas. Conviene organizar las carpetas y mantener una copia de los archivos importantes.

Una duda común

No. La RAM conserva datos de trabajo temporalmente; el almacenamiento guarda archivos de forma persistente.
