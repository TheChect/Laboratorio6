# Laboratorio 6 de Programación Web

Sitio NODO: hardware, redes y desarrollo web.

## Abrir el proyecto
Abre index.html en un navegador. No se necesita instalar paquetes ni tener Internet: las imágenes SVG, los estilos y Bootstrap 5.3.3 están incluidos.

## Estructura
- index.html: inicio y acceso a las tres páginas.
- pagina1.html: hardware.
- pagina2.html: redes.
- pagina3.html: desarrollo web.
- css/estilos.css: estilos compartidos.
- imagenes/: ilustraciones SVG originales del proyecto.
- vendor/: Bootstrap 5.3.3, distribuido bajo licencia MIT.

## Componentes
Cada página de contenido tiene tres tarjetas con imágenes y párrafos, un acordeón y una barra de navegación adaptable. El menú marca la página actual con la clase active y aria-current.
